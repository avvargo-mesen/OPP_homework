# OPP_homework

Учебный проект по объектно-ориентированному программированию на Python.

## Функционал

- Класс `BaseProduct` - абстрактный класс, родитель для всех продуктов
  - BaseProduct.__init__ - выбрасывает ValueError при quantity == 0

- `PrintMixin` - миксин, печатает информацию о создании объекта

- Класс `Product` - наследуется от PrintMixin и BaseProduct, описывает товар:
  - `name` - название
  - `description` - описание
  - `__price` - цена - приватный с геттером и сеттером
  - `quantity` - количество в наличии
  - `new_product()` - класс-метод (`@classmethod`), создаёт объект `Product` из словаря
  - Product.__str__ - возвращает строку "Название, X руб. Остаток: X шт."
  - Product.__add__ - возвращает сумму произведений цены на количество у двух товаров. Складывать можно только товары одного класса.

- Класс `Smartphone` - описывает товар, наследник `Product`:
  - `efficiency` — производительность
  - `model` — модель
  - `memory` — объём встроенной памяти
  - `color` — цвет

- Класс `LawnGrass` - описывает товар, наследник `Product`:
  - `country` — страна-производитель
  - `germination_period` — срок прорастания
  - `color` — цвет

- Класс `Category` - описывает категорию товаров:
  - `name` — название категории
  - `description` - описание категории
  - `__products` - приватный список товаров (объектов `Product`)
  - `add_product()` - метод для добавления товара в категорию. Принимает только объекты `Product` или его наследников.
  - `products` - геттер (`@property`), возвращает строку со всеми товарами
  - Category.__str__ - возвращает строку "Название, количество продуктов: X шт."
  - Category.average_price() - считает среднюю цену товаров, возвращает 0 если товаров нет.

- Атрибуты класса `Category`:
  - `category_count` - общее количество созданных категорий
  - `product_count` - общее количество товаров во всех категориях

  Оба атрибута увеличиваются автоматически при создании новой категории.
