# OPP_homework

Учебный проект по объектно-ориентированному программированию на Python.

## Функционал

- Класс `Product` - описывает товар:
  - `name` - название
  - `description` - описание
  - `__price` - цена - приватный с геттером и сеттером
  - `quantity` - количество в наличии
  - `new_product()` - класс-метод (`@classmethod`), создаёт объект `Product` из словаря
  - Product.__str__ - возвращает строку "Название, X руб. Остаток: X шт."
  - Product.__add__ - возвращает сумму произведений цены на количество у двух товаров.

- Класс `Category` - описывает категорию товаров:
  - `name` — название категории
  - `description` - описание категории
  - `__products` - приватный список товаров (объектов `Product`)
  - `add_product()` - метод для добавления товара в категорию
  - `products` - геттер (`@property`), возвращает строку со всеми товарами
  - Category.__str__ - возвращает строку "Название, количество продуктов: X шт."

- Атрибуты класса `Category`:
  - `category_count` - общее количество созданных категорий
  - `product_count` - общее количество товаров во всех категориях

  Оба атрибута увеличиваются автоматически при создании новой категории.
